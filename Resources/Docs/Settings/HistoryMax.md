**Allows adjusting the maximum number of media that is remembered in the playback history**

#####__IMPORTANT__

%{color:#FFFFD265} ❗% This also effects how many media items appear under 'Last Played' within the Taskbar jumplist (Jumplist can display max of 11)

%{color:#FFFFD265} ❗% Increasing the max history can potentially improve 'Shuffle' playback as the shuffle system excludes any media within the playback history to avoid repeats

######__INFO__

%{color:cyan} ❓% Valid values: **1-99**. When not manually set, defaults to 10.
