**Configures various options for the ProjectM visualization plugin**

#####__IMPORTANT__

%{color:#FFFFD265} ❗% Changes to this option will take place on the start of the next media.

%{color:#FFFFD265} ❗% Performance descreases the higher these values are set

######__Options__

 **Mesh X**
  + The width of the mesh, in pixels. Default is 64. Value must be higher than 0

 **Mesh Y**
  + The height of the mesh, in pixels. Default is 64. Value must be higher than 0
  
 **Texture Size**
  + The size of the texture, in pixels. Default is 1024. Value must be higher than 0
